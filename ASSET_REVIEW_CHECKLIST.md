# Portfolio evidence and asset checklist

This website includes no copied product screenshots. The conceptual cards, journey diagrams, and architecture views are labeled as diagrams or placeholders; they are not presented as screenshots of a running app.

## Acorda — screenshots to capture

Capture from a fresh, isolated emulator/profile using synthetic records. Do not use the user's primary device or real evidence.

- [ ] Agenda overview with fictional tasks and a synthetic date.
- [ ] Voice capture ready/active state, with no actual private recording or transcript visible.
- [ ] Saved local evidence browse/play state using synthetic audio metadata and a generated test image.
- [ ] Photo-First capture using a still-life test image with no person, document, or identifying location.
- [ ] Calma pattern selection and an active Cyclic Sigh session.
- [ ] Free pattern selection with five actual locked indicators, if the current UI build shows them. Mark as in development.
- [ ] Privacy erase-all confirmation dialog before confirmation, with no user content visible.
- [ ] Before/after Agenda evidence cards only if there are two real, approved UI versions to compare.
- [ ] Optional screen evolution timeline: one screenshot per validated checkpoint, with dates and behavior notes.

## Drop & Route — screenshots to capture

Current project materials describe file movement and folder access. Do not launch the downloaded app against real Desktop, Downloads, external drives, or network shares for portfolio capture.

- [ ] Confirm the current Xcode source/project location and match it to the compiled app artifact.
- [ ] Use a clean macOS test account or VM with disposable directories and synthetic files.
- [ ] Menu bar Shelf with a synthetic file and no personal filenames.
- [ ] Destination search with synthetic folder names.
- [ ] Pinned/recent destination state using a disposable local folder.
- [ ] Success and failure feedback for a synthetic move/copy, with no network-drive or company details.
- [ ] Before/after interaction comparison only after identifying the exact source/build for each version.

## Safe technical artifacts to prepare

- [ ] Acorda Room migration test report for schemas 1–6. Existing snapshots are private-source artifacts; publish only pass/fail summary, not schema or table internals.
- [ ] A focused audio recovery instrumentation report, clearly distinguishing executed tests from compiled test sources.
- [ ] A repeatable benchmark summary with the existing synthetic SQLite data, device/OS, warm-up, run count, medians, and the query-only limitation.
- [ ] A source-verified architecture diagram reviewed against the current `feature/subscription-implementation` working tree.
- [ ] Drop & Route's matching Xcode project/source and test evidence, if it is available and approved for inspection.
- [ ] A Product Owner-approved public contact method.

Do not include source files, database snapshots, raw user photos/audio, transcripts, tokens, local configs, account identifiers, deployment endpoints, or unredacted logs.
